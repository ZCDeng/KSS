# 自选股 MI 买卖点寻优报告

> 样本内选参 + 样本外评分；历史回测不代表未来。非投资建议。

## 方法

- 数据：本地 `cs_data` 真实日线
- 指标：MI / A（tqsdk 口径）+ mi_z + ADX + ATR
- 网格：N × entry × exit × filter
- 切分：前 70% 样本内看可交易性，**后 30% 样本外夏普为主评分**
- 执行：t 收盘信号 → t+1 开盘；成本买 0.1% / 卖 0.2%
- 预测分：`0.6*tanh(mi_z/2) + 0.4*tanh(a_mi/scale)`，ADX 弱时降权

## 预测算法（可复用）

```
每天收盘后:
  1. 算 A = close - close.shift(N), MI = SMA(A,N,1)
  2. 算 mi_z = rolling_z(MI, 60)
  3. 算 ADX(14) 作趋势过滤
  4. 若空仓且命中【买入规则】且通过【过滤】→ 次日开盘 BUY
  5. 若持仓且命中【卖出规则】→ 次日开盘 SELL
  6. pred_score = 0.6*tanh(mi_z/2) + 0.4*tanh((A-MI)/scale)
     ADX<20 时 pred_score *= 0.5
  7. 不在信号日收盘价成交；禁止用当日 close 当执行价
```
