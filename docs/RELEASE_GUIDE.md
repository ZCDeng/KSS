# KSS Desktop 发布指南

面向拿到这份 `.app` 的人——不是开发者，是被作者亲手交付这个应用的人。读完这篇你应该能回答：这是什么、我需要配什么凭证、配了之后能用到什么、装不上/用不了该怎么办。

## 这是什么

KSS Desktop 是一个 macOS 桌面应用，围绕科创板 + 创业板共 100 只样本股的量化研究工作台：每日看盘、选股推荐、板块复盘、AI 辅助分析、回测报告，外加一套跑在后台的定时任务（cron/launchd）持续更新数据。

它不是：

- 不是实盘下单系统——只写纸交易日志，不接触真实资金；
- 不是覆盖全 A 股的产品——样本池固定在科创 50 + 创业 50；
- 不是"开箱即用零配置"——部分功能需要你自己申请第三方凭证（见下）。

## 安装

1. 拷贝 `.app` 到 `/Applications`（或任意位置），双击打开。首次打开如果系统提示"无法验证开发者"，右键点"打开"确认一次即可——应用已过 Apple 公证（notarization），非未签名软件。
2. 首次启动会自动用 [`uv`](https://docs.astral.sh/uv/) 拉取 Python 运行时依赖（约 1-2 分钟，需联网）。**前提：这台 Mac 已装 `uv`**（`curl -LsSf https://astral.sh/uv/install.sh | sh`）。没装会在首启时给出明确的安装指引并停在那一步，不会崩溃或卡死。
3. 系统要求：macOS 14 (Sonoma) 及以上。

首启完成后应用会自动跑一次**启动自检**（数据目录可写、运行时可用、各凭证是否配置），结果在应用顶部横幅（有失败项时）和"设置"页常驻展示。

## 凭证与功能解锁

应用**不强制要求任何凭证就能打开**——缺凭证的功能会显示"未配置 X，去设置里填"的提示卡片而不是报错或空白页。凭证在"设置 → 密钥"页填写，存 macOS Keychain（不落明文文件）。

| 凭证 | 解锁什么 | 缺失时的表现 | 去哪申请 |
|---|---|---|---|
| **Tushare Token** | 今日看盘、推荐、板块复盘等绝大多数面板的行情/财务数据源 | 看盘面板显示"未配置 Tushare Token"提示卡 + 跳转设置按钮 | [tushare.pro](https://tushare.pro) 注册获取 |
| **Longbridge**（App Key / App Secret / Access Token） | 分时/实时行情采集 | 数据源测试显示未连通；相关后台任务跳过，不影响其余功能 | [长桥开放平台](https://open.longbridgeapp.com) 申请开发者账号 |
| **Telegram**（Bot Token / Chat ID / API URL 可选） | 后台定时任务（选股、复盘、预警等）的即时推送 | 任务照常运行、结果照常落盘，只是不推送到手机，日志/console 仍有输出 | 通过 [@BotFather](https://t.me/BotFather) 创建 Bot 拿 Token |
| **LLM key**（BYOK：OpenAI 兼容端点均可，含主/备两组） | Seesaw AI 助手、AI复盘生成、板块复盘点评、资讯情绪判定 | Seesaw 输入区显示"未配置 LLM key"提示卡；相关 LLM 增强内容跳过，基础数据不受影响 | 任意 OpenAI 兼容服务商（OpenAI / DeepSeek / 自建网关等） |

## 后台任务

应用装有一组 launchd 定时任务（数据更新、选股、复盘、预警等），清单见"设置 → 任务"，可在应用内启停、编辑排期、查看运行结果。任务的凭证解析优先读 Keychain，本机开发环境会额外回落读取 `.env`。

关机期间错过的任务，登录后由自检机制自动补跑（仅补跑标记为"可补跑"且当前启用的任务）。

## 日志

"设置 → 日志"页可直接查看/搜索所有后台任务的运行日志，无需打开终端或 Finder。单个任务日志超过 5MB 自动轮转，保留最近 3 代，超 14 天的轮转代自动清除。

## 已知限制

- **本机 IPC 无强认证。** 应用与后台 Python 进程（sidecar）之间的写操作走本地 socket（MCP + Swift 均可达），受 `KSS_APP_LIVE` / `KSS_MCP_LIVE` 环境开关 + 人工确认门控，但没有针对"同一用户下被注入的其它 agent 经由本地 stdio 触发写命令"这类场景的强认证（例如一次性 token）。这台 Mac 的其它本地进程理论上能在开关打开时冒充人工确认。当前威胁模型接受这个边界，不做进一步加固——如果这台机器上还跑着其它不受信任的自动化 agent，建议保持写开关默认关闭。
- **实时行情依赖第三方 API 可用性。** 东方财富分时端点在部分网络环境下不通，Longbridge 是当前唯一验证过的实时数据替代路径，需要自行申请开发者凭证。
- **首启需要联网 + 预装 `uv`。** 离线环境或缺 `uv` 时首启会停在依赖安装步骤，不会静默失败。
- **DuckDB 查询层尚未上线。** Seesaw 的 SQL 直查能力（统一数据库 + DuckDB 查询层）在 Phase C 交付，当前版本 Seesaw 走既有 bridge 命令面，不支持任意 SQL。

## 遇到问题怎么办

1. 先看"设置"页顶部的自检状态——`fail` 项（不是 `warn`）说明功能本身坏了，通常给出具体修复动作（如"重新初始化运行时"按钮）。
2. `warn` 项是缺凭证，不是故障——按上面的解锁矩阵去申请、填写即可。
3. 具体报错去"设置 → 日志"翻对应任务的日志文件。
